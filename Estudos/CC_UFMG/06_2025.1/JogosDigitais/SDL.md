# Simple Directmedia Layer
Biblioteca multiplataforma, possui uma camada leve de abstração, evitar nível mais baixo de Sistema Operacional e Drivers Gráficos (OpenGL, Vulkan, etc).

Diversos subsistemas imbutidos (Video, Audio, Timer, Events, File, I/O, Threading)
Extensões como .h separados (Image, Mixer, TTF, net, gfx)

## Setup
- Baixar release 2.32.2 no GitHub
- Baixar dependências em docs/README-linux.txt
```
./configure
make
make all
```
