Conda e environments: [[Configuração do Ambiente]]
- pipreqs/pipreqsnb: passa pelos arquivos .py ou .pynb de uma pasta e gera um requirements.txt com todas as bibliotecas utilizadas
- tqdm: permite criar barras de progresso de forma simples e eficiente, bom para acompanhar processamentos sem encher o terminal de prints.
- dotenv: gerencia variáveis do ambiente no arquivo .env (útil para guardar chaves de API)
- bs4/BeautifulSoup4: realiza parse de HTML e iteração nos elementos de forma simples, boa para webscraping
